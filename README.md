## 🌐 Sobre

Meu portfólio pessoal, feito só com **HTML, CSS e JavaScript puro**, no mesmo visual roxo do meu perfil.

🔗 **Online:** https://johnn5527.github.io/portfolio/

```bash
╭────────────────────────────────╮
│       JOHNNY SYSTEM v1.0       │
╰────────────────────────────────╯

✔ Efeito de digitação no topo
✔ Cards de projetos com estrelas via API do GitHub
✔ Animação ao rolar (respeita prefers-reduced-motion)
✔ Content-Security-Policy e nada de innerHTML
✔ Responsivo, sem framework e sem build

STATUS: NO AR 🚀
```

## ⚡ Rodar localmente

```bash
git clone https://github.com/Johnn5527/portfolio.git
cd portfolio
python -m http.server 8000     # abra http://localhost:8000
```

## 📁 Estrutura

```text
portfolio/
├── index.html   → páginas e seções
├── style.css    → tema roxo (#050505 → #6d28d9 → #a855f7)
└── script.js    → digitação, cards e animações
```

Para adicionar um projeto, é só incluir um item na lista `PROJETOS` do `script.js`.
